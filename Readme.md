
# CareerPilot 🚀
CareerPilot is an AI-powered resume analysis and career guidance system designed to help students and job seekers improve their resumes, identify skill gaps, and explore suitable career opportunities.

## 🎯 Objectives
- Analyze uploaded resumes.
- Identify technical skills and areas of improvement.
- Suggest suitable career paths based on skills.
- Recommend skills to learn for career growth.
- Help users prepare for job opportunities.
